# Digitama Routines Reels

Hosting publik video reels Digitama yang dibuat routine harian
([motion-engine](https://github.com/Z-tama/motion-engine), branch `claude/digitama-reels-harian`).

- Tiap video disimpan di `video/YYYY-MM-DD/`: `<nama>-9x16.mp4` dan `<nama>-9x16-sampul.jpg`.
  (Release tidak dipakai: sesi cloud Claude Code tidak diizinkan membuat release.)
- Link unduhan langsung: `https://raw.githubusercontent.com/Z-tama/Digitama-Routines-Reels/main/video/<tanggal>/<berkas>` —
  dipakai Repliz sebagai URL media saat menjadwalkan posting.
- Kapasitas: GitHub menyarankan repo < 5 GB (±12 MB per video ≈ 4,5 GB per tahun). Mendekati batas itu,
  video yang sudah tayang lebih dari 90 hari dipindah ke arsip lain dan riwayat repo dibersihkan.
- Jangan menyimpan berkas lain (kunci, data klien, draf internal) di repo ini: isinya publik.
